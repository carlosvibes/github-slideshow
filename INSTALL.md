# Installing graphifyy

Choose one of the following methods to install `graphifyy`.

## Recommended

`uv` puts `graphify` on your `PATH` automatically:

```sh
uv tool install graphifyy
```

## Alternatives

Using `pipx` (isolated install, also adds the CLI to your `PATH`):

```sh
pipx install graphifyy
```

Using `pip` (installs into the current Python environment):

```sh
pip install graphifyy
```
